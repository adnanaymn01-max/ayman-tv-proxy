AYMAN TV WEB
============
نسخة ويب مبنية على إعدادات مشروع Android المرسل.
ترفع الملفات الخمسة إلى استضافة تدعم PHP + cURL و HTTPS:
index.html, style.css, app.js, proxy.php, logo.png
ثم تفتح رابط الموقع.
مهم: الاستضافة الثابتة فقط (بدون PHP) لن تكفي لأن سيرفر IPTV الحالي HTTP والمتصفحات الحديثة قد تمنعه من صفحة HTTPS، والـ proxy يعالج CORS/Mixed Content.
